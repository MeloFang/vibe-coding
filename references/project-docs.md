# 项目文档模板集

> 三份项目级文档的模板。复制到项目里用，按实际内容删改。
> 配套流程见 `project-lifecycle.md`。

---

## 一、产品文档 `PRODUCT.md`

> **由 Agent 起草，用户审改。产品定义必须人来定，Agent 不许自己拍板。**

```markdown
# <产品名>

## 一句话定义
<用一句话说清这个程序解决什么问题。写不出一句话，说明还没想清楚。>

## 问题
**谁**：<目标用户>
**痛点**：<他现在遇到什么具体困难>
**现状怎么办**：<他现在的替代方案，以及为什么不够好>

## 目标用户与场景
- **主要用户**：<谁用得最多>
- **使用场景**：<在什么情况下会用，一次典型流程>

## 功能
### 必须有（MVP）
1. <功能1> —— <解决什么>
2. <功能2> —— <解决什么>
3. <功能3> —— <解决什么>

### 明确不做
- <不做的1> —— <为什么>
- <不做的2> —— <为什么>

## 成功标准
**怎么算做成了**（必须可验证）：
- [ ] <标准1>：<具体、可测>
- [ ] <标准2>：<具体、可测>
- [ ] <质量标准>：<性能/可靠性/易用性>

## 约束
- **技术栈**：<>
- **时间**：<>
- **依赖**：<外部服务/库>
- **数据**：<数据来源、规模、敏感度>

## 风险与未知
- <风险1> —— <影响> —— <应对>
- <未知1> —— <怎么搞清楚>

## 附：术语
核心名词定义放`GLOSSARY.md`，本文档只留必须先知道的。
```

**自查**：
- [ ] 一句话定义能说清"解决什么问题"，不只是"做个 XX"
- [ ] 成功标准是**可验证的**，不是"好用""快"
- [ ] "明确不做"不是空的（真写了东西）
- [ ] 约束里说了数据敏感度（涉及隐私/合规的必须写）

## 二、实施计划 `PLAN.md`

> 规划文档**只写指令不写实现**——不该出现大段代码。

```markdown
# 实施计划：<产品名>

> 依据 `PRODUCT.md`。每步带验收信号，一次只做一步。

## 步骤总览
| # | 步骤 | 依赖 | 验收信号 | 状态 |
|---|------|------|---------|------|
| 1 | <步骤1> | 无 | <怎么验> | ⬜ 未开始 |
| 2 | <步骤2> | 1 | <怎么验> | ⬜ 未开始 |
| 3 | <步骤3> | 1,2 | <怎么验> | ⬜ 未开始 |

状态标记：⬜ 未开始 / 🟡 进行中 / ✅ 已完成 / ⛔ 阻塞

---

## 步骤 1：<标题>

**目标**：<做完之后系统多了什么能力>

**做什么**：
- <指令性描述，不是代码>
- <指令性描述>

**验收**：
- [ ] <可执行/可观察的验证方式>
- [ ] <...>

**测试接缝**：<在这个项目的哪个接口上测>

**可能踩的坑**：<已知风险>

---

## 步骤 2：<标题>
...
```

**自查**：
- [ ] 每步有明确验收信号
- [ ] 粒度是一天左右能做完的，不是"实现全部功能"
- [ ] 每步是**垂直切片**（一条能跑通的细长路径），不是"先做完全部 A 再做全部 B"
- [ ] 依赖关系标清楚了
- [ ] 通篇没有大段实现代码

## 五、变更日志

| 日期 | 阶段变化 | 做了什么 |

**自查**：
- [ ] **完全不了解项目的人**读完能说出这程序干什么、做到哪了、下一步做什么
- [ ] "怎么接着做"是**具体动作**，不是"继续推进"
- [ ] 环境准备命令能复制粘贴直接跑
- [ ] 已知问题写了，不藏着
- [ ] **进度和各阶段状态是最新的**（不是三个月前的）

---

## 维护规则

1. **每个阶段结束立刻更新**，不要攒。
2. **更新时改日期和状态**，历史进变更日志。
3. **进度描述要具体**："步骤 5/8 完成，卡在步骤 6 的接缝设计"，不是"进展顺利"。
4. **决策定下来当场写 ADR**，不要等。
5. **术语随时补 `GLOSSARY.md`**，不要等。
6. 临时性的会话交接（跨Agent 接力）用 `handoff.md` 的格式写进系统临时目录，不要污染这个长期文档。

## 检查清单

交接给别人之前过一遍：

- [ ] 目标和非目标都写清了？
- [ ] 进度是准确的（不是乐观估计）？
- [ ] 下一步是具体动作？
- [ ] 已知坑写了？
- [ ] 敏感信息已脱敏（密钥、内网地址、真实数据）？
- [ ] 文档里的命令真的能跑通？
